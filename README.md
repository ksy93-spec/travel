# ✈️ TravelLog - 여행 플래너 & 가계부 (iOS PWA)

일본 오사카, 도쿄, 대만 등 여행을 위한 올인원 여행 플래너 및 가계부 웹 앱입니다.

## ✨ 주요 기능
- **📱 iOS 14 Pro 최적화**: 동적 뷰포트(`100dvh`) 및 하단 홈 바 안전 여백 지원
- **📅 일정표 (Itinerary)**: 일자별(Day 1 ~ Day N) 일정 관리, 구글 지도 맛집/명소 바로가기
- **💰 가계부 (Ledger)**: 현지 통화(JPY, TWD, USD 등) 입력 시 실시간 원화 자동 환산, 날짜별 소계 및 카테고리 필터
- **👥 1/N 정산 & 카카오톡 전송**: 친구들과의 더치페이 자동 계산 및 카톡 메시지 복사
- **📂 다중 여행 관리**: 오사카, 도쿄 등 여러 여행 계획을 누적 저장하고 자유롭게 전환
- **📶 100% 오프라인 동작 (PWA)**: 아이폰 홈 화면에 추가하면 비행기 모드나 데이터가 안 터지는 곳에서도 작동

## 📱 아이폰 홈 화면에 앱으로 추가하는 법
1. Safari에서 접속 (`https://ksy93-spec.github.io/travel/`)
2. 하단 중앙 **[공유 버튼 (네모 위 화살표 ↑)]** 터치
3. **[홈 화면에 추가]** 선택 후 **[추가]** 터치
4. 주소창 없는 전체화면 네이티브 앱으로 실행됩니다!
